# AI-Assisted Development Capstone

A capstone project exploring software development workflows enhanced by AI tools—from planning and implementation to testing and documentation.

## Description

This repository demonstrates building a Node.js application with AI-assisted development practices. It serves as a portfolio piece and learning artifact for modern, collaborative coding with intelligent assistants while maintaining clear conventions, version control, and maintainable JavaScript.

## Features

- Node.js application structure suitable for extension and experimentation
- Documented setup and usage for local development
- Conventional Commits and contributor-oriented project guidelines (`CLAUDE.md`)
- Standard Node.js tooling and ignore rules for a clean repository

## Tech Stack

- **Runtime:** Node.js
- **Language:** JavaScript
- **Package management:** npm

## Project status

This repository currently holds project documentation and repository setup only. Application code and a `package.json` will be added as the capstone progresses.

## Prerequisites

- **Node.js** 20 LTS or later ([Download Node.js](https://nodejs.org/))
- **npm** (included with Node.js)

## Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd my-capstone
   ```

2. When a `package.json` is available, install dependencies from the project root:

   ```bash
   npm install
   ```

## Usage

Once application scripts exist in `package.json`, run the project from the project root, for example:

```bash
npm start
```

For local development with auto-reload (once a `dev` script is defined):

```bash
npm run dev
```

Refer to inline documentation and `CLAUDE.md` for coding conventions when contributing or using AI assistants on this codebase.
